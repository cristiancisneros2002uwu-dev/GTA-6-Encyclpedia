Qué incluirá cada ficha de arma

Las fichas de armas documentarán el nombre exacto, tipo, disponibilidad, método de obtención, munición, mejoras y comportamiento observado. Los datos de daño o precisión solo se compararán cuando exista una prueba reproducible.

No se asignarán estadísticas numéricas a partir de impresiones visuales o de entregas anteriores.
