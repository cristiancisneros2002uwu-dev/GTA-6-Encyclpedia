Animales de GTA 6: fauna y registro

Recuento de fauna en la base de progreso y guía para registrar especies descubiertas.

Fauna registrada en la base de progreso

PowerPyx reporta 255 entradas de animales: 61 de caza, 35 peces, 18 mamíferos y 34 gatos y perros, además de otras subcategorías en el inventario. No debe confundirse este recuento de progreso con 255 especies distintas; la base puede agrupar ejemplares, variantes o categorías de seguimiento.

Para completar el inventario, consulta el menú Mapa > Progreso dentro del juego y registra cada entrada encontrada. No se publican aquí especies o ubicaciones que no estén enumeradas en la fuente consultada.
