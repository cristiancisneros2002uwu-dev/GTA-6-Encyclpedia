# Plantillas de publicación

1. Elige el archivo `ficha-*.md` que corresponda al contenido.
2. Completa también el JSON del mismo tipo que está en `_editorial/`.
3. Para la página pública, copia el cuerpo HTML ES o EN y sustituye todos los campos entre corchetes.
4. Consulta `_editorial/MAPA-SECCIONES-Y-CATEGORIAS.md` para escoger la categoría.
5. Sigue `_editorial/GUIA-PUBLICAR-MANUALMENTE.md` antes de subir cambios.

Los archivos de esta carpeta son material interno. No se enlazan desde el menú público ni son páginas de contenido. No publiques campos pendientes ni inventes información para completar una plantilla.
