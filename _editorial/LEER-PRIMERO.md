# Material editorial interno — GTA 6 Encyclopedia

Esta carpeta contiene herramientas para ampliar el sitio después del lanzamiento.

## Empieza aquí
1. `MAPA-SECCIONES-Y-CATEGORIAS.md`: rutas de las secciones y categorías existentes en español e inglés.
2. `GUIA-PUBLICAR-MANUALMENTE.md`: proceso para crear una página estática, enlazarla, actualizar el buscador y revisar sitemap.
3. `plantillas-publicacion/LEEME.md`: cómo utilizar las plantillas de ficha.
4. `GUIA-EDITORIAL-LANZAMIENTO.md`: criterios de verificación y publicación.

## Qué hay preparado
- 10 plantillas JSON de captura, una por tipo de contenido.
- 10 plantillas Markdown para redactar fichas.
- Cuerpos HTML de artículo ES/EN con las clases del diseño actual.
- Campos de publicación y SEO en cada JSON para preparar el alta de una página.

## Qué no hace este paquete
No convierte el sitio estático en un CMS, no publica automáticamente, no añade una API y no incorpora datos del juego que no hayan sido verificados. La publicación se hace copiando una página existente y siguiendo la guía.

Los archivos de esta carpeta son internos y no deben publicarse como páginas de contenido.
